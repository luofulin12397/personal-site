# 决策史

`PRODUCT.md` 与 `DESIGN.md` 只写**现在成立的规则**。规则是怎么来的、被替换掉的旧方案是什么，记在这里；逐字原文见 git 历史（2026-11-28 重写前的最后版本：提交 `8c803de`）。

按时间顺序，一条一行判断。改规则前先看对应条目的理由。

| 日期 | 决定 | 理由 / 代价 | 现行出处 |
|---|---|---|---|
| v1 | Astro 脚手架被替换为零构建静态页 | 脚手架实现粗糙，构建链对一个单页不划算 | 已被 v3 推翻 |
| v2 | 「工程图纸与批注」：冷灰地面、朱红批注色 ≤5%、终端是唯一暗色物体；数字必须可核验；不做 eyebrow / 编号 / CTA | 给同行看可证伪的材料；`view-source` 本身是作品 | 已被 v3 推翻 |
| v2 | 分两层：首页讲人，`projects/rag/` 讲一个项目 | 首页不塞架构图，项目页不重复自我介绍 | PRODUCT「分层」，仍有效 |
| 2026-11-16 | v3「可拆解的系统」：石墨绿黑 + 信号芽绿、React / Vite、硬错位投影；参考实现 `fulin-portfolio` 只借色板与组件 | 视觉与交互复杂度上来，接受构建链；失去「双击即开」 | DESIGN 全文 |
| 2026-11-16 | 内容底线放开：数字不再强制可核验 | 用户拍板；仍建议标注实测 / 估算 / 目标 | PRODUCT「内容尺度」 |
| 2026-11-16 | 字号下限 12px 不随参考版放宽到 11px | 可读性默认约束 | DESIGN Typography |
| 2026-11-16 | 发布：原定 Vercel，实际改为 GitHub Pages + Actions 构建 `dist/`；站内链接一律经 `site()` 生成 | 推 main 即上线；Pages 在 `/personal-site/` 子路径下 | README「部署」 |
| 2026-11-16 | 首页主体改为「人 + 项目 + 分享」，取舍与「这一页」后置；项目拆解升为一级分支，顶栏常驻分区切换器 | 首页曾经变成作品柜，人不见了；拆解页入口几乎看不到 | ADR 0002 |
| 2026-11-21 | `03 文章` 升为第三个分区；正文用 `Block[]` 数据驱动，详情走 `?p=slug` | 首页三条纯文本没地方放长文；Pages 无 SPA 回退 | PRODUCT「分区」 |
| 2026-11-23 | 中文字体改由系统 Noto Sans SC 变量字体实例化为 400/500/700 再子集化，1373 字零缺字 | 长文引入大量新字，旧子集掉字形；代价是每字重约 429KB | README「改字体」 |
| 2026-11-24 | 项目拆解统一七拍叙事合同 | 三篇拆解各自长成不同结构 | ADR 0001 |
| 2026-11-25 | 项目拆解不再缩成窄列；`.wrap` 全宽，只限段落行宽；工作台双栏紧随首屏 | Wren 页一度锁进 76ch，两侧大面积留空 | ADR 0001、DESIGN Layout |
| 2026-11-27 | WrenAI 工作台：三泳道 13 节点 + 函数级源码注解 Inspector | 右栏信息太少；用户要「点节点看输入、处理、代码」 | DESIGN Components |
